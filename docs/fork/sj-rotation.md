# Ночная ротация комнаты SaluteJazz

Механизм «запустил и забыл» для канала на SaluteJazz: раз в сутки сервер сам
создаёт новую комнату и переезжает в неё, клиенты получают её через подписку.

## Почему SaluteJazz, а не VK Calls

VK звонки нельзя создавать автоматически:

- старый OAuth (`oauth.vk.com/authorize`) закрыт для приложений из нового
  кабинета: любой новый app получает `Security Error`, независимо от типа
  (Web, Сайт, Android);
- VK ID выдаёт токен нового образца, которому недоступен классический API
  (`calls.start` отвечает `error 1051`), а без него звонок не создать;
- звонок, созданный руками, не считается запущенным, пока в него не зайдёт
  живой человек.

Провайдер `salutejazz` в движке реализует `RoomCreator` и создаёт комнату одним
анонимным POST, без токена и аккаунта. Комната сразу рабочая, человек не нужен.

## Как устроено

| Компонент | Путь | Назначение |
|---|---|---|
| конфиг генератора | `/etc/olcrtc-sj/gen.yaml` | `mode: gen`, провайдер `salutejazz` |
| скрипт ротации | `/usr/local/bin/sj-rotate` | создать комнату, переключить инстанс |
| таймер | `sj-rotate.timer` | ежедневно в 03:00 МСК |

Что делает `sj-rotate`:

1. Запускает `olcrtc-gl /etc/olcrtc-sj/gen.yaml` и берёт последнюю строку
   вывода - это `комната:пароль`.
2. Проверяет формат; если генерация не удалась, старый адрес остаётся.
3. Обновляет `instances.room_id` в базе копии панели - оттуда комнату берут
   интерфейс и лента подписки.
4. Обновляет `subscriptions.updated_at`, чтобы у клиентов сменился `#update`
   и они перечитали список.
5. Правит `room.id` в `/etc/olcrtc-panel/instances/2/config.yaml` - именно этот
   файл читает движок. `instance prepare` его не перегенерирует: она выставляет
   только права, конфиг пишет процесс панели при создании инстанса.
6. Перезапускает `olcrtc-instance@2` и ждёт в журнале `Link connected`.

Подписка привязана к инстансу (`source_instance_id`), URI собирается на каждый
запрос, поэтому смена комнаты не меняет адрес подписки.

## Проверка

```sh
systemctl start sj-rotate.service      # разовая ротация
journalctl -t sj-rotate -n 3 -o cat
sqlite3 /var/lib/olcrtc-gl-panel/panel.db "select room_id from instances where id=2"
grep -A1 '^room:' /etc/olcrtc-panel/instances/2/config.yaml
curl -sk https://127.0.0.1:62594/sub/<slug>/olcbox | grep salutejazz
```

Все три источника должны показывать одну и ту же комнату.

## Откат

```sh
systemctl disable --now sj-rotate.timer
```

Комната останется текущей; дальше менять её можно вручную через панель.

## Ограничения

- Ротация обрывает активные сессии на 20-30 секунд, поэтому и стоит в 03:00.
- VK-канал (`olcrtc-instance@1`) автоматически не переезжает: звонок надо
  создавать руками. Он остаётся в подписке вторым сервером как запасной.
- `liveness.timeout` у инстансов, созданных панелью, по умолчанию 5 секунд -
  слишком мало, сессии прибиваются на ровном месте. Ставим 30 секунд в базе и
  в конфиге.
