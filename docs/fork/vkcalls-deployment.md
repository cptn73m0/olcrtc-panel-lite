# Развертывание VK-канала рядом с рабочим

Схема, собранная 2 ноября 2026: копия панели с поддержкой провайдеров
ghostlane-форка работает рядом с боевой панелью и не мешает ей.

## Что где стоит

| Компонент | Путь / порт | Назначение |
|---|---|---|
| Боевая панель | `/usr/local/bin/olcrtc-panel`, `:62593` | работает как раньше |
| Копия панели | `/usr/local/bin/olcrtc-panel-gl`, `:62594` | провайдеры `vkcalls`, `salutejazz`, `mtslink`, `max` |
| Старый движок | `/usr/local/bin/olcrtc-fixed` | инстанс 10, Jitsi |
| Новый движок | `/usr/local/bin/olcrtc-gl` | инстансы копии, VK Calls |
| TLS-терминатор | nginx `:8443`, сертификат Let's Encrypt | подписки по валидному HTTPS |

Каталог инстансов общий: `/etc/olcrtc-panel/instances`. Базы, ключи и TLS у
панелей разные.

## Диспетчер движков

Юнит `olcrtc-instance@.service` не знает, чей перед ним инстанс. Это решает
один общий drop-in `30-engine-dispatch.conf` и два скрипта.

`/usr/local/bin/olcrtc-prepare <id>` (запускается от root):

1. Смотрит, есть ли ID в базе копии панели.
2. Пишет метку в `/run/olcrtc-engine/<id>`: `gl` или `legacy`.
3. Запускает `instance prepare` соответствующей панели.

`/usr/local/bin/olcrtc-exec <id>` читает метку и запускает нужный бинарник.

Добавление нового инстанса в копию панели не требует ручных файлов: метка
появится сама при первом старте.

Откат: удалить `/etc/systemd/system/olcrtc-instance@.service.d/30-engine-dispatch.conf`,
вернуть `20-fixed-binary.conf`, `systemctl daemon-reload`.

## TLS для подписок

Приложение проверяет сертификат подписки, самоподписанный CA панели оно не
принимает (`tls: unknown certificate` в журнале панели).

- Хостнейм: `2-26-192-83.sslip.io` - wildcard DNS сервиса sslip.io, резолвится
  в IP сервера без покупки домена.
- Сертификат: `acme.sh --issue --standalone --httpport 80`, автопродление в cron.
- nginx `:8443` принимает TLS и проксирует в копию панели на `:62594`
  (`proxy_ssl_verify off`, потому что внутри самоподписанный).
- Порт 80 оставлен свободным: его занимает acme.sh при продлении.

Проверка: `curl https://2-26-192-83.sslip.io:8443/sub/<slug>/olcbox` должен
отдавать `sub.md` без предупреждений о сертификате.

## Подписка

- Формат: `/sub/<slug>/olcbox` (стандартный `sub.md`). Короткий `/sub/<slug>`
  отдаёт компактный формат OLCRTC Client, где `vkcalls` не проходит белый
  список совместимых пар, поэтому лента пустая.
- Запись в подписке привязана к инстансу (`source_instance_id`), URI
  собирается на каждый запрос. Смена комнаты в панели меняет содержимое
  подписки без смены её URL.
- Клиент обновляет список по `#refresh` (10 минут) или вручную.

## Что проверено

- Смена имени инстанса и записи: подписка обновилась, клиент подхватил.
- Смена комнаты: инстанс перезапустился, подписка отдала новую комнату,
  клиент переехал сам, трафик пошел.
- Диспетчер: инстанс 1 запускается `olcrtc-gl`, инстанс 10 - `olcrtc-fixed`,
  боевой инстанс при этом не перезапускался.
